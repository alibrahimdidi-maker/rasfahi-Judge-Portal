# މުޞްޙަފުގެ PNG ޞަފުޙާތައް

މި ފޯލްޑަރަށް މަދީނާ މުޞްޙަފުގެ 604 ޞަފުޙާ PNG ގޮތުގައި ލައްވާ:

    001.png, 002.png, ... 604.png

- ޞަފުޙާތައް ވާންވާނީ މަދީނާ މުޞްޙަފު (15 ފޮޅުވަތް) — ކިންގް ފަހުދު ކޮމްޕްލެކްސް ޗާޕު.
- ނަން ދޫކުރާ ގޮތް ތަފާތުނަމަ ސެޓިންގްސް > "ފައިލް ނަމުގެ ގޮތް" ބަދަލުކުރައްވާ ({p3}, {p}, {p4}).
- ފޮޅުވަތްތައް ރަނގަޅަށް ރޮނގުން ފާހަގަ ކުރެވޭތޯ ސެޓިންގްސް > "ކެލިބްރޭޝަން ޗެކްކުރޭ" އިން ބައްލަވާ.
