## 2. Firebase ސެޓްއަޕް (އެއް ފަހަރު)

1. <https://console.firebase.google.com> → **Add project**.
2. **Build → Authentication → Get started → Sign-in method → Google → Enable**.
3. **Authentication → Settings → Authorized domains** → `YOUR_GITHUB_USERNAME.github.io` އިތުރުކުރައްވާ.
4. **Build → Firestore Database → Create database** (Production mode، ސާވަރު ގާތް ތަނެއް).
5. **Firestore → Rules** → `firestore.rules` ގެ ހުރިހާ ލިޔުމެއް ޕޭސްޓްކޮށް، `bootstrapEmail()` ގައި ތިބާގެ ގޫގުލް އީމެއިލް (ކުޑަ އަކުރުން) ލިޔެ **Publish**.
6. **Project settings → Your apps → Web (</>)** → ލިބޭ `firebaseConfig` އަގުތައް `js/firebase-config.js` އަށް ކޮޕީ ކުރައްވާ.
   ހަމަ އެ ފައިލްގައި `BOOTSTRAP_SUPERADMIN` (ހަމަ އެ އީމެއިލް) އާއި `PUBLIC_BASE_URL` ލިޔުއްވާ.
7. (އިޚްތިޔާރީ) އީމެއިލް އޮޓޯ ފޮނުވުމަށް: **Extensions → Trigger Email from Firestore** (collection: `mail`). މިއަށް Blaze ޕްލޭން ބޭނުންވޭ.
   މި އެކްސްޓެންޝަން ނެތިއްޔާވެސް، އެޑްމިން ސްކްރީނުން "މެއިލް އެޕުން ފޮނުވާ" ބަޓަނުން މެއިލް ފޮނުވޭނެ.

## 4. ފުރަތަމަ ފަހަރަށް ބޭނުންކުރުން

1. ސުޕަރ އެޑްމިން އީމެއިލް އިން ލޮގިން ވުމުން އޮޓޯ ސުޕަރ އެޑްމިން އެކައުންޓް ހެދޭނެ.
2. **މުބާރާތާއި ބައިތައް** → މުބާރާތެއް ހަދާ → **ސެޓިންގްސް** އިން "ހިނގަމުންދާ މުބާރާތް" ހޮވާ.
3. ބައިތައް (ކެޓަގަރީ): ގޮފި (ބަލައިގެން / ނުބަލައި)، ޢުމުރުފުރާ، މުޤައްރަރު (ފޮތް ނުވަތަ ސޫރަތް ވަކިން)، ދަރިވަރަކަށް ސުވާލު ޢަދަދު (1–100، ޑިފޯލްޓް 3)، ފޮޅުވަތުގެ މަދު/ގިނަ ޢަދަދު، ރުބްރިކް.
4. **ޔޫޒަރުން** → ކޮންމެ މީހަކަށް އަމިއްލަ ގޫގުލް އީމެއިލާއެކު ރޯލެއް:
   ޗީފް ޖަޖު، ޖަޖުން، ސެކްރެޓަރީ، އެޑްމިން ސެކްރެޓަރީ، ސުޕަވައިޒަރ، ކޮންސަލްޓެންޓް، ޗެކްއިން ސްޓާފް (ޓެބްލެޓް)، ދަރިވަރު ސްކްރީން، ވެއިޓިންގ ރޫމް ސްކްރީން.
   ޑިސޭބަލް / އެނޭބަލް އަދި ރޯލު ބަދަލުކުރެވެނީ ސުޕަރ އެޑްމިނަށް އެކަނި.
5. **އިޢުލާނާއި ފޯމު** → ރަޖިސްޓްރޭޝަން ހުޅުވާ → ފޯމުގެ ލިންކް ޝެއަރކުރޭ.
6. **އެޕްލިކޭޝަންތައް** → ބަލާ / އެޑިޓް → "ގަބޫލުކޮށް ދަރިވަރަކަށް ހަދާ" (ރެޖި ނަންބަރު އޮޓޯ، ދަރިވަރު ސޭވްވަނީ **އައިޑީ ނަންބަރާއެކު**)
   ނުވަތަ "ރަނގަޅުކުރަން ފޮނުވާ" (ބައިވެރިޔާއަށް މެއިލް ދާނެ؛ ކުރިން ފޮނުވި ފޯމު ހުޅުވޭނީ ހަމަ އެ އީމެއިލް، ނަން، މޯބައިލް ޖެހުމުން).
7. **ސެޝަނާއި ޝެޑިއުލް** → ސެޝަން، ޗީފް ޖަޖު، ޖަޖުން (ތަރުތީބުން)، ދަރިވަރުންނާއި ތަރުތީބު. ނުވަތަ "އޮޓޯ ޝެޑިއުލް".

### ސުވާލުގެ ޤަވާޢިދު (ސޮފްޓްވެއަރ އިން ޔަޤީންކުރާ ކަންކަން)
- ސުވާލު ނަގަނީ ސޮފްޓްވެއަރގައި ހިމެނޭ ޤުރްއާނުން؛ ހުރިހާ ސުވާލެއް **މުޅި އާޔަތްތަކުން**، **އެއް ސޫރަތެއްގެ ތެރެއިން**، **އެއް ޞަފުޙާއެއްގެ ތެރޭގައި** (ދެވަނަ ޞަފުޙާއަކަށް ނުދޭ).
- ފޮޅުވަތުގެ ޢަދަދު ބައިގެ ސެޓިންގްސް އަށް ބަލައިގެން (ޑިފޯލްޓް 3–7).
- ސެޝަނެއްގައި 100 ގްރިޑް (ސެޓިންގްސް އިން ބަދަލުކުރެވޭނެ) ނުނެގެނީސް ސުވާލުގެ **ފެށޭ ތަނާއި ނިމޭ ތަން ތަކުރާރު ނުވާނެ**.
- ތަރި: 75+ = ★، 80+ = ★★، 85+ = ★★★، 90+ = ★★★★، 95+ = ★★★★★ (ސެޓިންގްސް އިން ބަދަލުކުރެވޭނެ).

## 6. މުޞްޙަފުގެ PNG ވަރޝަން
ޓެކްސްޓްގައި އެއްވެސް ކުށެއް ފާހަގަވެއްޖެނަމަ: `mushaf/` ފޯލްޑަރަށް 604 ޞަފުޙާ ލާފައި **ސެޓިންގްސް → ދަރިވަރު ސްކްރީނުގައި ދައްކާނީ → PNG**.
ލައިވް ކޮންޓްރޯލުން ވެސް ސްކްރީން މޯޑް ބަދަލުކުރެވޭނެ. "ކެލިބްރޭޝަން ޗެކްކުރޭ" އިން ރަތް ރޮނގުގެ ތަން ހަމަކުރައްވާ.

## 7. ޤުރްއާން ޓެކްސްޓުގެ މަސްދަރު
- **KFGQPC Uthmanic Hafs v3** (ކިންގް ފަހުދު ކޮމްޕްލެކްސް) — ޓެކްސްޓް، ޞަފުޙާ އަދި ފޮޅުވަތް؛ [quran.ws/quran-text](https://github.com/quran-ws/quran-text) (CC-BY-4.0) މެދުވެރިކޮށް. 6,236 އާޔަތް ޗެކްކުރެވިފައި.
